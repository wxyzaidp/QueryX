### Quick Start

Install QueryX Template by running either of the following:

- Install NodeJS LTS from [NodeJs Official Page](https://nodejs.org/en/?ref=horizon-documentation) (NOTE: Product only works with LTS version)

Clone the repository with the following command:

```bash
git clone https://github.com/horizon-ui/QueryX.git
```

Run in the terminal this command:

```bash
npm install
```

Then run this command to start your local server

```bash
npm run dev
```

### Your API Key is not working?

- Make sure you have an [OpenAI account](https://platform.openai.com/account) and a valid API key to use ChatGPT. We don't sell API keys.
- Make sure you have your billing info added in [OpenAI Billing page](https://platform.openai.com/account/billing/overview). Without billing info, your API key will not work.
- The app will connect to the OpenAI API server to check if your API Key is working properly.

# AI Chat Template

This template provides a modern chat interface for interacting with LLMs including Google's Gemini and OpenAI's GPT models.

## Setup

1. Clone the repository
2. Install dependencies
```bash
npm install
# or
yarn
```

3. Set up your API keys:
   - For Google AI Gemini: Get an API key from https://makersuite.google.com/app/apikey
   - For OpenAI: Get an API key from https://platform.openai.com/account/api-keys

4. Create a `.env.local` file with your API keys:
```
# OpenAI API key (optional if using Gemini)
NEXT_PUBLIC_OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx

# Google AI Gemini API key
NEXT_PUBLIC_GEMINI_API_KEY=AIzaxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

5. Run the development server
```bash
npm run dev
# or
yarn dev
```

## Features

- Modern, responsive UI with dark mode
- Support for multiple AI models:
  - Google Gemini Pro
  - OpenAI GPT-4o
  - OpenAI GPT-3.5 Turbo
- Streaming responses for real-time interaction
- Markdown and code formatting support
- Mobile-friendly design

## Usage

Enter your API key when prompted. The app will remember your key for future sessions.

Type your message in the input field at the bottom of the screen and click "Submit" to get a response.
